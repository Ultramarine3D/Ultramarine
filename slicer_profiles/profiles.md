# Slicer profiles
Slicer profiles for Ultramarine are currently best used with 0.4 mm and 0.6 mm nozzles. 
Both sizes are recommended, but the 0.6 mm nozzle is the better default for most prints because it gives a more forgiving balance of speed, strength, and reliability and test show better consistency with the current profiles.

Right now, the 0.6 mm setup is also the one that works with OrcaSlicer. If you are starting from scratch or want the smoothest path with the current profiles, use the 0.6 mm nozzle and OrcaSlicer first.

## Prusa slicer
Prusa slicer profiles are not yet available. If you are using PrusaSlicer, you can use the OrcaSlicer profiles as a starting point, but you will need to adjust settings to match your printer and filament.
